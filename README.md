# Sim World — VibeHub co-creation binding

This repository is the co-creation binding for the **Sim World** project on VibeHub.
Game source and assets live locally and are deployed via the official VibeHub CLI;
the release artifacts on VibeHub are the single source of truth for the playable build.

The co-creation verification files and CODEOWNERS in this repo are managed by
`vibehub collaboration-setup`; do not edit them by hand.

## Play
See the VibeHub project page (slug `sim-world`) for the live play link.
